# Документация TrafficSkip

Эта папка собирает все материалы по концепту **SKIP THE TRAFFIC**: от продуктовой идеи до юридических документов для MVP.

## Карта документов

| Документ | Что внутри | Когда читать |
| --- | --- | --- |
| [product-vision.md](product-vision.md) | Проблема, цель продукта, аудитория, сценарии, анти-индуцированный подход, аналитика, MVP | Чтобы быстро понять смысл проекта и его продуктовую ценность |
| [terms-of-use.md](terms-of-use.md) | Пользовательское соглашение для B2C-сервиса | Чтобы показать юридическую рамку использования продукта |
| [privacy-policy.md](privacy-policy.md) | Политика конфиденциальности с учетом геолокации и ФЗ-152 | Чтобы показать работу с персональными данными и privacy-рисками |
| [legal-document-prompt.md](legal-document-prompt.md) | Исходное ТЗ/промпт для подготовки legal-документов | Чтобы показать, как были сформулированы требования к документам |

## Быстрый маршрут чтения

1. Начать с [product-vision.md](product-vision.md), чтобы понять продукт.
2. Посмотреть legal-пакет: [terms-of-use.md](terms-of-use.md) и [privacy-policy.md](privacy-policy.md).
3. Если интересна методика подготовки документов, открыть [legal-document-prompt.md](legal-document-prompt.md).

## Примечание

Legal-документы описывают учебный MVP и не заменяют юридическую экспертизу. Для реального запуска нужно адаптировать их под фактическую инфраструктуру, процессы обработки данных, партнеров, платежи и модель монетизации.
